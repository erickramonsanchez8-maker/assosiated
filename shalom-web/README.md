# Shalom — Sabor y Paz

Sitio web independiente de **Shalom — Sabor y Paz, Brunch & Dinner**, separado del panel interno ASSOCIATED y del portal de operaciones HESED.

## Archivos
- `index.html`: sitio comercial principal.
- `shalom-tienda.html`: página de pedidos/tienda.

## Publicación con GitHub Pages
1. Importa el contenido de esta carpeta a un repositorio dedicado llamado, por ejemplo, `shalom-web`.
2. En ese repositorio abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
4. Guarda y espera la publicación.

## Notas
- Se conserva el HTML original del sitio comercial.
- La tienda sigue siendo una página independiente y se mantiene el nombre de archivo al que apunta el sitio.
- Este paquete es una web estática; no incorpora por sí solo una base de datos ni un sistema de reservas/pagos de servidor.
- El repositorio fuente actual contiene otros proyectos; este directorio está aislado para facilitar su extracción a un repositorio independiente.
