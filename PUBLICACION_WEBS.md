# Publicación de HESED y del sitio de SHALOM

## Contenido publicado en GitHub Pages
- `docs/index.html`: entrada que redirige al portal HESED.
- `docs/hesed.html`: portal de acceso a SHALOM, BEFIT y LA HUERTA.
- `docs/shalom.html`: sitio comercial de SHALOM.
- `docs/shalom-tienda.html`: catálogo y solicitud de pedidos de SHALOM.
- `docs/.nojekyll`: evita el procesamiento de Jekyll para el sitio estático.

## Configuración
1. Abre el repositorio en GitHub y entra en **Settings → Pages**.
2. Selecciona **Deploy from a branch**, la rama publicada y la carpeta `/docs`.
3. Guarda y confirma que GitHub reporte un despliegue correcto.

La existencia de los archivos no demuestra que Pages esté activo. La dirección prevista del portal depende del nombre del repositorio y de la configuración real de Pages.

## Antes del lanzamiento comercial de SHALOM
- Confirmar dirección, ubicación, WhatsApp, teléfono, Instagram y horarios oficiales.
- Validar carta, precios, disponibilidad y fotografías.
- La tienda actual prepara solicitudes, pero no procesa pagos ni guarda pedidos en una base de datos central.
- No usar datos sensibles en archivos públicos. El panel local todavía requiere autenticación y almacenamiento central seguros para producción.

## Alcance de HESED
HESED es el portal administrativo para los dos propietarios y las tres empresas. La web comercial y la tienda de SHALOM se mantienen separadas del sistema administrativo.
