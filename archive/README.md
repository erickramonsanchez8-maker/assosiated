# Fuentes de recuperación

Esta carpeta conserva versiones originales que ya no se sirven como páginas activas. Se guardan únicamente para permitir una comparación o recuperación controlada durante el desarrollo de HESED.

- `shalom-panel-baseline.html`: versión de referencia del panel anterior a la integración local.
- `mi-parcela-original-3d.html`: fuente original de Mi Parcela con visualización 3D. La integración de HESED excluye esa vista.

No enlazar estos archivos desde la navegación activa ni usarlos como sistema de producción.
